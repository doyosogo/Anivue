# Anivue Screenshots

Store repository and portfolio screenshots in this directory.

Do not commit placeholder or generated images. Capture real screenshots from a
local production preview or deployed build after the app has loaded live AniList
metadata.

Committed screenshots:

- `homepage-desktop.png`
- `anime-details.png`
- `membership-modal.png`
- `trailer-modal.png`
- `my-list.png`

Recommended additional filenames:

- `homepage-mobile.png`
- `search-results.png`
- `viewing-history.png`

Recommended capture sizes:

- Desktop: 1440 x 1000
- Tablet: 834 x 1112
- Mobile: 390 x 844

Before capturing:

- Run `npm run build`
- Preview with `npm run preview` or use the deployed URL
- Verify key routes load directly
- Add one title to My List
- Open at least one anime details page so Recently Viewed appears
- Avoid screenshots that imply episode playback, payment, or account creation
